# Product Overview

## What is Steward?

Steward is a personal finance application for managing accounts, transactions, budgets, and financial insights in one place.

The project is being built from the ground up to explore modern technologies, application architecture, and engineering practices while creating a complete full-stack application.

## Problem

Personal financial information is often spread across bank applications, spreadsheets, budgeting tools, and investment platforms.

This makes it difficult to understand overall financial health, review spending, manage budgets, and track progress over time.

Steward aims to provide a clear and organized view of a user's finances through a single application.

## Product Direction

Steward will focus on the core workflows needed to explore and manage personal financial data:

- Reviewing financial accounts
- Managing and categorizing transactions
- Creating and updating monthly budgets
- Monitoring spending and budget progress
- Viewing financial summaries and trends

The initial version will use realistic seeded data and lightweight authentication rather than real financial institution integrations.

## Project Purpose

The purpose of Steward is to build a complete application that supports realistic financial workflows while providing room to explore frontend architecture, backend design, databases, testing, and deployment.

The project should remain manageable for a solo developer and avoid unnecessary production complexity.
