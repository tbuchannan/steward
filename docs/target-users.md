# Target Users and Primary Use Cases

## Primary User

Steward is intended for an individual who wants a clearer view of their personal finances without relying on multiple applications or spreadsheets.

The initial version is designed around a single user managing their own financial information.

## User Needs

The primary user needs to:

- View financial accounts in one place
- Review and organize transactions
- Understand where money is being spent
- Create and manage monthly budgets
- Track budget progress
- View summaries of their financial position

## Primary Use Cases

### Review financial position

The user opens the dashboard to review account balances, recent transactions, spending, and budget progress.

### Manage accounts

The user creates and updates financial accounts such as checking, savings, credit card, investment, loan, and cash accounts.

### Manage transactions

The user creates, edits, categorizes, searches, and filters transactions.

### Create a monthly budget

The user assigns spending amounts to categories and monitors progress throughout the month.

### Investigate spending

The user reviews spending by category and examines the transactions contributing to that spending.

### Update application preferences

The user manages settings such as theme and display preferences.

## Secondary Users

Developers or reviewers may use the seeded demo experience to explore the application and understand its workflows and architecture.

They are not the primary product user, and their needs should not override the personal-finance experience.

## Initial Constraints

The MVP assumes:

- One user per account
- One base currency
- Manually managed or seeded financial data
- No real bank or brokerage integrations
- No household collaboration
