# MVP Scope

## Objective

The Steward MVP should provide a complete personal-finance workflow that allows a user to explore accounts, transactions, budgets, and financial summaries using realistic seeded data.

The MVP should be polished enough to demonstrate the main product experience without requiring real financial institution integrations.

## Included

### Authentication

- Demo login or lightweight authentication
- A predefined demo user
- Seeded financial data available after login

### Application Shell

- Responsive application layout
- Navigation between primary sections
- Light and dark themes
- Basic user settings

### Dashboard

- Account balance summary
- Monthly income and spending summary
- Budget progress
- Recent transactions
- Spending by category
- Items requiring attention

### Accounts

- View financial accounts
- Create an account
- Edit an account
- Archive or remove an account
- Support common account types:
  - Checking
  - Savings
  - Credit card
  - Cash
  - Loan
  - Investment

### Transactions

- View transactions
- Create transactions
- Edit transactions
- Delete transactions
- Categorize transactions
- Search transactions
- Filter transactions
- Paginate transaction results

### Budgets

- View a monthly budget
- Navigate between months
- Create and edit budget categories
- Assign budget amounts
- Track spending against budget amounts
- Display remaining and overspent amounts
- Save or cancel budget changes

### Data

- Realistic seeded accounts
- Realistic seeded transactions
- Seeded categories
- Seeded monthly budget data

### Quality

- Responsive layouts
- Accessible core interactions
- Validation and useful error states
- Loading and empty states
- Tests for important workflows
- Deployment and setup documentation

## Optional After the Core MVP

These features may be included after the primary workflow is complete:

- CSV transaction imports
- Net-worth history
- Spending analytics
- Investment summaries
- Recurring transaction detection
- Financial goals

## MVP Completion Criteria

The MVP is complete when a user can:

1. Sign in through the demo experience.
2. View a populated dashboard.
3. Review and manage financial accounts.
4. Create, edit, categorize, search, and filter transactions.
5. Create and edit a monthly budget.
6. See budget changes reflected in financial summaries.
7. Update basic preferences.
8. Use the primary workflows on desktop and mobile layouts.
9. Access a deployed version of the application.
